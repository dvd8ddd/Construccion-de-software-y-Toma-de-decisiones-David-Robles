Preguntas

¿Que importancia tiene AJAX en el desarrollo de RIA's (Rich Internet Applications)?

AJAX es importante porque permite que las paginas web sean más dinámicas y rápidas, ya que puede mandar y recibir información del servidor sin tener que recargar toda la página.

¿Qué implicaciones de seguridad tiene AJAX? ¿Dónde se deben hacer las validaciones?

AJAX puede ser inseguro si no se controla bien, porque las peticiones pueden ser manipuladas desde el cliente. Aunque las validaciones siempre se tienen que hacerse en el sevidor, ya que el cliente no es confiable

¿Qué es JSON?

Es un formato de texto que se usa para enviar datos entre el cliente y el servidor, ademas que es muy usado en aplicacion web especialmente cuando se trabaja con AJAX
